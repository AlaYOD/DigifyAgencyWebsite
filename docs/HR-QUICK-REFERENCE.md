# Digify HR quick reference

## Publish a vacancy

1. Open **Careers → Job Postings**.
2. Select **Create**, complete the English and Arabic fields, department, and employment details.
3. Set **Status** to Published only after both Arabic title and description are complete.
4. Save and use **Preview** to check the public vacancy.

## Review applications

Open **Careers → Job Applications**. HR can see candidate names, contact details, CV actions, ratings, notes, and exports. IT sees operational rows but candidate names and PII remain redacted.

## Move a candidate

Use the application stage action or the Careers applications board. Select the destination stage and save. Every move records the previous stage, new stage, actor, and timestamp.

## Download a CV

Open an application and choose **Download CV**. The link is private, signed, expires after 15 minutes, and is available only to users with PII access.
